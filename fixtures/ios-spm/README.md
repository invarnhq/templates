# ios-spm fixture

A minimal SwiftUI iOS app, SPM-only (no CocoaPods, no Carthage), with one unit test target. Used by templates that target the iOS stack with `pods: false`.

## What's checked in

- `project.yml` — [XcodeGen](https://github.com/yonaskolb/XcodeGen) project spec. Source of truth.
- `IosSpmDemo/` — SwiftUI app source (~20 LOC).
- `IosSpmDemoTests/` — one XCTestCase with one passing test.

## What's NOT checked in

- `IosSpmDemo.xcodeproj/` — generated by `xcodegen generate`. Gitignored.
- `DerivedData/`, `.build/` — Xcode build output. Gitignored.

## Generate the project locally

```bash
cd fixtures/ios-spm
xcodegen generate
```

You'll need [XcodeGen](https://github.com/yonaskolb/XcodeGen) installed (`brew install xcodegen`). Invarn's runner image ships with it.

## Build it locally

```bash
cd fixtures/ios-spm
xcodegen generate
xcodebuild -project IosSpmDemo.xcodeproj -scheme IosSpmDemo -destination 'platform=iOS Simulator,OS=latest,name=iPhone 16' build
```
